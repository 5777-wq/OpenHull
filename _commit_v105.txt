One waterline per candidate: fix the split that hid a defect (v1.0.5)

The v1.0.4 re-verification confirmed every number of the previous round
bit for bit and then asked one question worth chasing: 10 of the 35
off-axis designs had their OWN shaft power BELOW the reference power,
so a balance should exist above their design speed - yet the solve
refused them with the same message as the group above the reference.

The cause is not the bracketing: the scan evaluated TWO waterlines per
candidate.  The design-point effective-power call took Ayre's own
default (1.025*Lpp); the reference-speed solve took the task book's
ABSOLUTE length_waterline_m (285 m, the JBC's own waterline, carried
unchanged onto candidates whose Lpp spans 231-301 m - a +20 % Ayre LCB
correction on a 231 m hull, -7.7 % on a 301 m one).  For a 301 m
candidate the two calls disagreed by 8.4 % in effective power, which is
how a hull came to "absorb more than the reference at the band floor
but less at its own design speed" - impossible for one hull - and was
refused as unbalanceable.

- One rule now: `_candidate_lwl` = Ayre's standard 1.025*Lpp, used by
  the design point and the axis solve alike.  The task book's LWL keeps
  its declared role in the weather criterion.
- Pinned by an independent-path identity: PE at the design speed /
  eta_D must reproduce the recorded shaft power for EVERY candidate.
  It holds to 1.1 % now; it was 8.4 % with the task-book waterline.
- The CLI run had the same split (PE with the standard, propeller
  factors with Lpp) - one value now serves both: the declared LWL when
  the task book carries one, else 1.025*Lpp.  Effect on the 45,000 t
  in-band case: D 7.425 -> 7.417 m, eta_o 0.5632 -> 0.5647, delivered
  13,473.8 -> 13,440.6 kW.
- The off-axis disclosure is per candidate and classified
  (`reference_speed_note` + `off_reference_causes`): balance below the
  band / above it / validity gap.  The acceptance run goes from 35
  off-axis (one-sentence, partly wrong explanation) to 17, all
  `below band`; the Pareto pool recovers, 8 -> 26 designs.
- The reference-power refusal now names both powers (DHP x eta_D x
  eta_S -> required P_E) instead of "target 21000 kW" beside
  "dhp_kw 41336".
- Two more constructed boundaries became tolerant (tip-clearance gate
  at 0.75 T, eta_o sanity band), same class as N3.

Validation item 17 carries the corrected acceptance numbers, the
before/after and the defect history.  Tests 381 -> 384.
