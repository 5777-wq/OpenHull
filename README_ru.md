> Design the shell that carries it all.

Открытая цепочка инструментов параметрического проектирования судов,
управляемая ИИ-агентами.

Из технического задания (тип судна, дедвейт, эксплуатационная скорость,
район плавания) конвейер агентов формирует главные размерения,
гидростатику, теоретический чертёж, оценки сопротивления / пропульсива /
остойчивости и выходные чертежи (DXF).

## Статус

**v0.3 выпущен** — этап 3 завершён, контур характеристик замкнут: оценка сопротивления по Айру, пропульсивные коэффициенты Холтропа с решателем сервисной скорости, проектирование винта серии B Варгенингена (опубликованная регрессия, проверка кавитации по Бурриллу, проектирование по тяге), большая остойчивость с критериями IS Code 2.2 и критерием ветра и волнения, плюс оптимизатор пространства проектирования (`openhull optimize`), просеивающий соотношения размерений к выполнимым проектам с диаграммой Парето. Проверено на эталонном судне JBC, отчёте DTMB 1712 и измеренных данных MP687 NMRI (см. [VALIDATION.md](VALIDATION.md)). Запуск: `openhull run examples/taskbook_bulk_carrier.yaml`.

## Принципы проектирования

1. Каждый результат должен быть прослеживаем до формулы или опубликованного источника
2. Верификация по опубликованным судам-эталонам важнее новых функций
3. Эмпирические формулы декларируют область применимости и отклоняют выходящие за её пределы данные
4. Всё, что выражается формулой, автоматизируется; остальное остаётся за инженером
