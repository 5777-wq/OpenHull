# 方法与数据来源（中文）

OpenHull 的核心纪律：**一个数字进不了白名单，就不许出现在结果里**。
本页按模块列出所用方法、出处与验收要点；完整验收记录（22 条，含全部
数字）见英文 [Validation](validation.md) 页。

## 主尺度与重量

| 方法 | 来源 | 验收 |
|---|---|---|
| 载重量比法 | Xie《船舶设计原理》§2.2.2 式(2-3)/(2-4)/(2-5) | 35,000 t 散货船算例零循环复现 |
| 钢料/舾装重量 | 立方模数与指数法（同书 §2.2.2；林焰 §2.1.3 交叉校验） | 两书互检一致 |
| 重量浮力平衡 | 诺曼系数迭代；收敛准则 \|W−B\|/W ≤ 0.1–0.5 %（张剑/张静《船体结构强度》§3.2.2 式 3-27） | 收敛 3 次内 |

## 船型

| 方法 | 来源 | 验收 |
|---|---|---|
| 母型船 | DTMB 1712 报告 Series 60 Cb 0.80 型值表（公开域，数字化入库） | 装载/压载排水量锚点 |
| 变换 | Lackenby 法（《船舶原理》上册；二阶项忽略与教材一致） | 目标 Cb/LCB 残差 ≤ 1e-4 |

## 静水力与稳性

| 方法 | 来源 | 验收 |
|---|---|---|
| 静水力积分 | 梯形/辛普森法则（《船舶原理》上册第 2 章） | 解析形体复现 |
| 大倾角 GZ | 《船舶原理》上册第 3 章 | 上册算例 |
| IS Code 2.2 六项衡准 | IMO 2008 完整稳性规则（imorules.com + 决议 A.562(14) PDF 双源） | 逐条衡准测试 |
| 恶劣风浪衡准 | IS Code 2.3（同上双源） | 面积比锚点 |

## 性能

| 方法 | 来源 | 验收 |
|---|---|---|
| 艾亚阻力 | 《船舶原理》下册 §7（速度-长度带 0.50–1.20、C₀ 数字化带） | 表 7-5/7-7a-b 转录 |
| Holtrop 推进因子 | 下册 §5-2/5-3 式(5-38)–(5-52)（逐式对照扫描页核） | DTMB 1712 表 39/31：航速 ±0.32 kn |
| B 系列螺旋桨 | Bernitsas/Ray/Kinley 密歇根报告 **No. 237**（1981 年 5 月，39+47 项多项式与 Rn 修正，转录双读+图 41 像素级叠加验收） | MP687 实测 ηo 均差 2.8 %；表 8-12 终局设计差 0.07 kn |
| Burrill 空泡校核 | 下册 §6-5 式(6-14)–(6-16)；商船限界线取书内四锚点 | 表 6-2/8-29 读数 |

## 耐波性（两级）

| 方法 | 来源 | 验收 |
|---|---|---|
| 波浪关系/遭遇频率 | 下册式(2-7)/(2-98)/(2-99)（p.344/367） | 表 3-1 波浪对 9 行复现 |
| 横摇固有周期 | 式(3-27)/(3-39)/(3-49)/(3-48)（p.389–391；0.58 系数含 g 的舍入已数值验证） | 书算例 156 m/244 m；货船 8–13 s 带 |
| 阻尼定量 | 式(3-51)/(3-57)–(3-59)、表 3-6/3-7、μ 区间（p.392–394） | 表 3-6 四行复现；能量平衡自洽 |
| 纵摇/垂荡周期 | 式(4-55)/(4-57)/(4-60)、式(4-62) 恢复式（p.427–428） | 田宫交叉 1.1 %；恢复式 0.5 % |
| 零航速 RAO | capytaine（Apache-2.0 可选扩展）——只算水动力，质量/惯量/刚度来自白名单链 | 网格体积互差 0.1 %；长波垂荡→1；顶浪横摇对称 |

## 速度损失（Kwon 方法）

| 项 | 内容 |
|---|---|
| 来源 | Cheng 等, JMSE 2025, 13(1), 42（MDPI 开放获取 CC-BY）§2.2 逐字印刷 Kwon 2008 系数表；原始文献 Kwon 1981 Newcastl­e 博士论文——两份均已归档页核 |
| 公式 | ΔV/V₁ [%] = Cμ·ΔR·C_F；V₁ = Fr·√(Lpp·g)；适用域 Cb 0.55–0.85、Fr 0.05–0.30 |
